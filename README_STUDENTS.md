# ShopEase Pentest Challenge

Welcome to the ShopEase bug bounty program. Your goal is to identify and exploit as many vulnerabilities as possible.

## Challenge List
You can find vulnerabilities across the following categories:
- Authentication & Session Management
- SQL Injection (Basic to Advanced)
- Cross-Site Scripting (Reflected & Stored)
- Access Control & Business Logic Flaws
- File Handling & SSRF
- Information Disclosure

## Lab Guidelines
- Only test on the provided lab environment.
- Do not attempt to attack other students' instances.
- Report all findings as if this were a professional security audit.

## Resetting the Lab
If you need to reset the environment to a clean state, notify your instructor.
